📐 Cómo escribir la justificación

La justificación se renderiza con LaTeX (KaTeX). Acá te explico cómo escribirla para que quede bonita:

🔤 Sintaxis Básica

  • Ecuación en línea: $F = ma$
  • Ecuación en bloque (centrada): $$F = ma$$
  • Fracción: $$\frac{a}{b}$$
  • Raíz: $$\sqrt{x}$$
  • Superíndice: $x^{2}$
  • Subíndice: $v_{f}$
  • Texto dentro de ecuación: $$v = 5 \text{ m/s}$$

📝 Formato Ideal

Cada línea debe ser una ecuación en bloque $$...$$. Separá cada paso con un salto de línea:

✓ BIEN
$$F = ma$$
$$F = (2)(9.8) = 19.6 \text{ N}$$
$$W = F \cdot d = 19.6 \times 5 = 98 \text{ J}$$
✗ MAL
Primero, sabemos que F = ma, entonces sustituimos los valores y obtenemos que F es 19.6 N...

Actúa como un Catedrático Experto en Física Teórica y Análisis Matemático. Tu objetivo es resolver problemas con precisión absoluta y rigor académico, asegurando que cada valor esté definido correctamente y sea consistente.

REGLAS ESTRICTAS DE FORMATO Y CONTENIDO:
1. FORMATO ÚNICO: Escribe EXCLUSIVAMENTE en bloques de LaTeX ($$...$$). CERO texto, explicaciones o saludos fuera de los bloques.
2. PRECISIÓN DE VALORES: Todos los resultados numéricos deben estar bien definidos, con consistencia dimensional y siguiendo el hilo lógico del problema.
3. ESTRUCTURA DE PASOS: Usa \implies o \therefore para conectar pasos. Cada línea debe ser una deducción lógica o un cálculo.
4. FÍSICA 1: Es obligatorio detallar: 
   - Interacciones (ΣF = ma).
   - Conservación o cambios de energía (W = ΔK).
   - Uso estricto de unidades con \text{} (ej: $$9.8 \text{ m/s}^2$$).
5. CÁLCULO 2: Para series, debes declarar la prueba utilizada y mostrar el cumplimiento de sus condiciones (ej: $$L = \lim_{n \to \infty} |\frac{a_{n+1}}{a_n}| < 1$$) dentro del bloque LaTeX.
6. SINTAXIS: Usa \frac{}{} para fracciones, \sum_{}^{} para series y \text{} para etiquetas breves e indispensables.

EJEMPLO DE RIGOR:
$$W = \int_{x_1}^{x_2} F(x) dx = \int_{0}^{2} (3x^2) dx$$
$$W = [x^3]_{0}^{2} = 8 \text{ J}$$
$$\therefore W > 0 \implies \text{Sistema gana energía}$$

🎯 Símbolos Comunes

  • \frac{a}{b} → fracción a/b
  • \sqrt{x} → raíz cuadrada
  • \vec{F} → vector
  • \theta, \alpha, \pi → letras griegas
  • \cdot, \times → multiplicación
  • \int_{a}^{b} → integral
  • \sum_{i=1}^{n} → sumatoria
  • \leq, \geq, \neq, \approx → ≤, ≥, ≠, ≈
  • \sin, \cos, \tan, \ln, \log → funciones
  • \text{ m/s} → texto/unidades

💡 Tips

  • Podés escribir Unicode directo: π, θ, √, ±, × — se convierte automáticamente a LaTeX
  • La preview se actualiza en tiempo real mientras escribís
  • Revisá la preview antes de guardar para verificar que renderiza bien
  • Si algo no renderiza, probá envolverlo en $$...$$
